## 通用约定

- 每票交付完整可观察流程，包含所需持久化、平台或服务接入、UI 与测试，不按技术层分票。
- 复用 NSH 根组件交互入口，在单一应用环境边界替换外部行为；纯逻辑按需补测试，平台流程需实机证据。
- 首次使用外部接口的票负责核实来源、协议和样例；不能以模拟数据完成验收。无法验证时保留阻塞并说明事实，不自动缩减承诺。
- 当前只有计数器骨架，无需单独的大范围预重构；T01 在功能切片内先建立应用环境边界再完成启动行为。
- 六批按规格顺序交付并验收。下列边仅表示技术前置，不把批次顺序伪装成代码依赖；前沿任务也须遵守当前批次的执行安排。
- 后续新数据模块须接入 T05 的删除和关联规则；各批真实流程验收是批次完成条件，T28 不替代前面各批验收。
- 发布时创建父规格的子任务、使用原生阻塞关系并标记 ready-for-agent；不改写或关闭父规格正文。

## 任务

### T01：选择已有游戏并普通启动

- 批次：1
- 阻塞于：无
- 交付：自动发现和手选安装目录、保存默认目录、处理无安装和路径失效，并启动真实游戏；在这条流程中引入已确认的应用环境测试边界。

### T02：扫码添加并保存米哈游账号

- 批次：1
- 阻塞于：T01
- 交付：核实扫码接口，展示完整二维码状态并保存受 Windows 保护的授权；重启后恢复账号，失效可重新扫码。

### T03：切换已保存账号并启动游戏

- 批次：1
- 阻塞于：T01、T02
- 交付：核实凭据与游戏登录衔接，用两个真实账号验证切换；授权有效免扫码，运行中提示正常退出而不强制结束。

### T04：独立管理游戏 UID 与验证账号归属

- 批次：1
- 阻塞于：T01
- 交付：未登录也能创建和选择 UID 数据空间；添加账号后只关联经验证的归属，跨 UID 数据隔离。

### T05：移除账号与独立删除历史记录

- 批次：1
- 阻塞于：T02、T04
- 交付：移除凭据保留 UID 数据，重加账号恢复关联；独立删除操作先列出涉及的 UID，后续模块遵循此规则。

### T06：下载并安装游戏，支持断点恢复

- 批次：2
- 阻塞于：T01
- 交付：核实官方资源清单，选择目标安装并完成可启动的游戏下载；支持暂停、继续、关闭保存及重启后手动恢复。

### T07：下载并应用增量更新

- 批次：2
- 阻塞于：T06
- 交付：识别版本差异并下载增量包，退出游戏后应用更新；修改期间禁止对应目录启动，完成后可运行目标版本。

### T08：预下载并在更新可用时安装

- 批次：2
- 阻塞于：T07
- 交付：展示可预下载版本，下载和续传资源但不立即应用；更新可用后提示并复用资源安装。

### T09：校验并修复游戏文件

- 批次：2
- 阻塞于：T06
- 交付：以真实资源清单发现缺失或损坏文件并修复，退出游戏后修改文件；恢复后校验通过且可启动。

### T10：为指定账号自动完成游戏签到

- 批次：3
- 阻塞于：T02
- 交付：核实游戏签到服务及授权，固定一个账号，打开、跨日和休眠恢复时检查；包含有限重试、人工处理提示和手动重试。

### T11：接入社区签到并展示独立结果

- 批次：3
- 阻塞于：T10
- 交付：核实社区签到入口，接入同一指定账号和执行流程；社区失败不阻止其他可执行项。

### T12：接入云游戏签到并展示独立结果

- 批次：3
- 阻塞于：T10
- 交付：核实云游戏签到授权和入口，接入单账号执行流程；明确区分成功、已签到、失败和待处理。

### T13：展示三类签到奖励日历

- 批次：3
- 阻塞于：T11、T12
- 交付：核实奖励来源，展示日期及各服务真实结果；失败不标已领取，手动重试只处理未完成项。

### T14：导入导出 UIGF 祈愿记录

- 批次：4
- 阻塞于：T04
- 交付：支持约定 UIGF 版本、UID 选择、预览、导入前备份和去重；展示记录，导出 v4.2，提示其他游戏数据未处理。

### T15：展示保底与稀有度统计

- 批次：4
- 阻塞于：T14
- 交付：核实卡池规则与基础数据，从已导入记录生成统计；明确历史缺失时可推断范围，不能伪造完整历史。

### T16：查看并手动维护成就进度

- 批次：4
- 阻塞于：T04
- 交付：核实成就目录来源，按 UID 浏览和标记成就，重启后保留进度，不写游戏服务器。

### T17：导入导出 UIAF 成就记录

- 批次：4
- 阻塞于：T16
- 交付：核实 UIAF v1.1 字段，预览、自动备份并合并完成状态；缺失归属时选择 UID，支持标准格式导出。

### T18：备份恢复抽卡与成就记录

- 批次：4
- 阻塞于：T14、T17
- 交付：整体备份与标准导出分开，迁移 UID 记录且不含凭据；恢复预览并合并，换机后重新扫码。

### T19：导入并浏览背包快照

- 批次：5
- 阻塞于：T04
- 交付：核实可用数据来源及导入格式，展示实际武器、圣遗物和材料记录与采集时间；快照不相加，旧快照需明确选择。

### T20：创建角色养成计划并计算材料

- 批次：5
- 阻塞于：T04
- 交付：核实角色、天赋及材料数据，保存当前和目标等级、突破、天赋，计算需求并扣除手填库存。

### T21：创建武器养成计划并计算材料

- 批次：5
- 阻塞于：T20
- 交付：复用计划管理与库存输入，覆盖武器等级和突破，保存计划并展示材料需求。

### T22：使用背包库存计算养成缺口

- 批次：5
- 阻塞于：T19、T20、T21
- 交付：角色和武器计划可选择同 UID 的背包库存，显示采集时间并计算材料缺口，避免跨 UID 混用。

### T23：迁移养成计划与背包快照

- 批次：5
- 阻塞于：T18、T19、T20、T21
- 交付：扩展整体备份，计划冲突由用户选择，背包默认较新完整快照；验证全业务记录迁移及凭据排除。

### T24：浏览精选插件目录

- 批次：6
- 阻塞于：T01
- 交付：核实首批候选来源、格式和权限并提交条目确认；展示已确认插件的来源、版本和安装位置，不接任意商店源。

### T25：安装、更新与卸载已确认插件

- 批次：6
- 阻塞于：T24
- 交付：针对已确认兼容类型完成实际安装、用户触发更新和卸载，显示结果并保留可核对的安装状态。

### T26：用固定版本 UnlockerIsland 可选注入启动

- 批次：6
- 阻塞于：T03、T25
- 交付：核实接口、运行要求和发布条件，管理固定版本并主动启用注入；默认普通启动，失败明确报告且不静默回退。

### T27：更新注入模块并保留普通启动

- 批次：6
- 阻塞于：T26
- 交付：验证新版本兼容性后提供用户触发的更新，更新后分别验证注入和普通启动，不承诺维护模块内部功能。

### T28：交付可安装的 Windows 首期构建产物

- 批次：6
- 阻塞于：T05、T08、T09、T13、T15、T22、T23、T27
- 交付：核实整体复用许可，提供可追溯源码和 Windows 构建产物，在干净环境完成安装与六批关键流程验收。
