## What to build

验证 Windows 国服官服普通启动与米游社授权的边界。启动器可直接打开游戏，游戏登录和账号切换由官方客户端处理。米游社授权用于后续签到与祈愿记录功能。

批次 1，拆分编号 T03。范围依据 [T03 的实机决策记录](https://github.com/IannTao/genshin-go/blob/main/docs/validation/t03.md)与[单账号规格修订](https://github.com/IannTao/genshin-go/issues/30)。

## Acceptance criteria

- [ ] 记录普通启动与米游社授权的边界。扫码成功和授权有效提示只报告米游社授权状态。
- [ ] 通过 NSH 根组件验证无米游社授权或授权失效时均可普通启动，授权失效提示和重新扫码入口仍可用。
- [ ] 在独立 Windows 启动器配置下，无米游社授权时通过普通启动打开真实国服客户端。
- [ ] 运行 Rust 格式检查、Clippy、NSH 检查及完整交互测试并记录结果。
