## What to build

核实凭据与游戏登录衔接，用两个真实账号验证切换；授权有效免扫码，运行中提示正常退出而不强制结束。

批次 1；批准的拆分编号 T03。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 记录凭据到国服客户端登录的实际衔接依据，不混淆米游社 Cookie 与游戏授权。
- [ ] 使用两个真实账号分别保存、选择并启动，确认游戏中的身份与选择一致；有效授权无需重复扫码。
- [ ] 游戏运行时提示用户正常退出后切换，不强制结束；失效授权进入重新扫码流程。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
