## What to build

核实接口、运行要求和发布条件，管理固定版本并主动启用注入；默认普通启动，失败明确报告且不静默回退。

批次 6；批准的拆分编号 T26。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实固定版本的接口、构建或产物方式、运行要求及许可条件，保留复用依据。
- [ ] 用户主动启用后完成真实注入启动；默认关闭并保留独立普通启动入口。
- [ ] 失败明确报告，是否普通启动由用户选择；账号切换和运行状态约束仍有效。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
