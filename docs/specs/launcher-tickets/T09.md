## What to build

以真实资源清单发现缺失或损坏文件并修复，退出游戏后修改文件；恢复后校验通过且可启动。

批次 2；批准的拆分编号 T09。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 使用已核实版本清单识别缺失、损坏文件，显示校验结果。
- [ ] 退出游戏后修复；修复期间阻止对应安装启动，不修改其他目录。
- [ ] 修复完成重新校验通过且真实游戏可启动，失败明确显示。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
