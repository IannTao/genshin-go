## What to build

支持约定 UIGF 版本、UID 选择、预览、导入前备份和去重；展示记录，导出 v4.2，提示其他游戏数据未处理。

批次 4；批准的拆分编号 T14。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 支持 UIGF v4.0–v4.2 原神祈愿记录导入和 v4.2 导出，严格验证所需字段。
- [ ] 写入前预览新增、重复与冲突数量并备份，按 UID 归属和记录去重；不能识别 UID 时明确选择。
- [ ] 展示导入记录并可往返导出；其他游戏数据未处理须提示，旧版与损坏文件有明确结果。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
