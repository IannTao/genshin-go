## What to build

核实可用数据来源及导入格式，展示实际武器、圣遗物和材料记录与采集时间；快照不相加，旧快照需明确选择。

批次 5；批准的拆分编号 T19。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实可用背包来源和导入格式；若无法取得真实数据，记录阻塞，不以样例替代验收。
- [ ] 按 UID 只读浏览武器、圣遗物与材料，保留并显示原始采集时间。
- [ ] 新快照替换不累加；默认较新完整快照，选择旧快照需明确操作，导入先预览和备份。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
