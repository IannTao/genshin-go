## What to build

移除凭据保留 UID 数据，重加账号恢复关联；独立删除操作先列出涉及的 UID，后续模块遵循此规则。

批次 1；批准的拆分编号 T05。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 移除账号删除受保护的授权并保留 UID 数据。
- [ ] 重新添加同一账号且验证归属后恢复关联，不复制或重复创建历史记录。
- [ ] 删除历史记录是独立操作，先显示涉及的 UID，仅删除所选范围；后续数据模块复用同一规则。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
