## What to build

核实扫码接口，展示完整二维码状态并保存受 Windows 保护的授权；重启后恢复账号，失效可重新扫码。

批次 1；批准的拆分编号 T02。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实扫码服务、所需请求和返回凭据，记录可重复验证的接入依据。
- [ ] 界面涵盖等待扫描、等待确认、成功、过期、取消和网络失败；过期可刷新。
- [ ] 凭据使用 Windows 保护，重启可恢复多个账号，失效后可重新扫码；不把扫码成功当作游戏登录完成。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
