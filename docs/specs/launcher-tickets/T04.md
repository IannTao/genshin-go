## What to build

未登录也能创建和选择 UID 数据空间；添加账号后只关联经验证的归属，跨 UID 数据隔离。

批次 1；批准的拆分编号 T04。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 不登录也能建立和切换 UID 数据空间，重启后保留。
- [ ] 米哈游账号标识与游戏 UID 分开，账号关联必须有归属验证依据，不能凭输入 UID 自动声称归属。
- [ ] 不同 UID 的数据互相隔离；接口测试可控验证归属，不依赖模拟结果宣称线上验证通过。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
