## What to build

识别版本差异并下载增量包，退出游戏后应用更新；修改期间禁止对应目录启动，完成后可运行目标版本。

批次 2；批准的拆分编号 T07。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 从已有安装识别版本差异，获取正确增量包，支持下载暂停与恢复。
- [ ] 游戏运行中可下载，退出后才应用；修改期间阻止对应目录启动。
- [ ] 更新后版本和文件有效，能启动目标版本；失败明确显示且不误报完成。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
