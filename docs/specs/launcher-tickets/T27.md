## What to build

验证新版本兼容性后提供用户触发的更新，更新后分别验证注入和普通启动，不承诺维护模块内部功能。

批次 6；批准的拆分编号 T27。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 候选更新先验证实际兼容性并提供版本信息，由用户选择是否更新。
- [ ] 完成组件更新后分别验证注入启动和普通启动。
- [ ] 失败不误报成功、不静默回退；维护范围仅为启动器侧适配。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
