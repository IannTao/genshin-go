## What to build

核实官方资源清单，选择目标安装并完成可启动的游戏下载；支持暂停、继续、关闭保存及重启后手动恢复。

批次 2；批准的拆分编号 T06。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实官方资源清单及下载、安装协议，记录版本与资源来源。
- [ ] 从目标目录选择到真实下载、安装和普通启动完整可用。
- [ ] 支持暂停、继续和断点恢复；关闭时保存，重启后显示未完成任务并等待手动继续。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
