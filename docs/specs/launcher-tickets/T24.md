## What to build

核实首批候选来源、格式和权限并提交条目确认；展示已确认插件的来源、版本和安装位置，不接任意商店源。

批次 6；批准的拆分编号 T24。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 逐项核实候选插件来源、版本、类型、安装位置、权限及兼容格式，并取得首批条目确认。
- [ ] 界面展示已确认的精选目录及条目详情，目录加载失败有明确结果。
- [ ] 不开放任意商店源，不实现镜像加速或第三方启动器页面开发框架。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
