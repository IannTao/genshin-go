## What to build

核实游戏签到服务及授权，固定一个账号，打开、跨日和休眠恢复时检查；包含有限重试、人工处理提示和手动重试。

批次 3；批准的拆分编号 T10。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实游戏签到的具体入口、日期边界和授权要求；保存一个指定账号，切换游戏账号不改变它。
- [ ] 打开、跨日及休眠恢复后检查当天状态，跳过已完成项；关闭期间不执行。
- [ ] 网络超时有限次重试，登录失效或人工验证标待处理；提供仅重试未完成项的按钮。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
