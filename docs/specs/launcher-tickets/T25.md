## What to build

针对已确认兼容类型完成实际安装、用户触发更新和卸载，显示结果并保留可核对的安装状态。

批次 6；批准的拆分编号 T25。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 以已确认插件类型验证实际安装、用户触发更新及卸载。
- [ ] 界面显示当前版本、安装位置及操作结果，重启后状态可核对。
- [ ] 网络或安装失败不显示成功，操作限定在该插件管理范围；不自动更新。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
