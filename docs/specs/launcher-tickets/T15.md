## What to build

核实卡池规则与基础数据，从已导入记录生成统计；明确历史缺失时可推断范围，不能伪造完整历史。

批次 4；批准的拆分编号 T15。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实卡池与稀有度所需规则和基础数据，按 UID 及相应卡池口径统计。
- [ ] 展示保底相关指标和稀有度统计，重复导入不改变统计结果。
- [ ] 历史不足时明确展示推断限制，不把缺失记录当作零或已知完整历史。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
