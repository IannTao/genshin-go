## What to build

核实成就目录来源，按 UID 浏览和标记成就，重启后保留进度，不写游戏服务器。

批次 4；批准的拆分编号 T16。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 成就进度按游戏 UID 写入 SQLite，重启后恢复各 UID 的进度。

- [ ] 核实成就目录和版本数据，显示成就及当前完成状态。
- [ ] 未登录也可按 UID 手动标记并保存进度，重启恢复且不同 UID 隔离。
- [ ] 只更新启动器记录，不修改游戏服务器；接入既有历史删除规则。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
