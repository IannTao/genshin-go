## What to build

展示可预下载版本，下载和续传资源但不立即应用；更新可用后提示并复用资源安装。

批次 2；批准的拆分编号 T08。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实预下载资源和生效条件，展示目标版本及下载状态。
- [ ] 支持暂停、继续、关闭保存及重启后手动恢复，下载完成不自动应用。
- [ ] 更新可用时提示安装并复用已下载资源，遵守运行与文件修改互斥。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
