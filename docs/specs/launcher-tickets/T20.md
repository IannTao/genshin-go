## What to build

核实角色、天赋及材料数据，保存当前和目标等级、突破、天赋，计算需求并扣除手填库存。

批次 5；批准的拆分编号 T20。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实角色等级、突破、天赋及材料数据来源，按 UID 保存当前与目标状态。
- [ ] 界面展示角色材料需求，支持手填库存并计算缺口。
- [ ] 未登录可用，重启恢复，跨 UID 隔离并接入历史删除规则；用可核算样例验证材料结果。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
