## What to build

在启动器打开、跨日和休眠恢复时，为指定的单个米哈游账号检查并执行当天未完成的社区签到。关闭启动器期间不执行。

批次 3；批准的拆分编号 T11。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 核实社区签到入口、授权和日期边界，不把未定义社区任务擅自加入范围。
- [ ] 在同一指定账号及自动触发流程执行社区签到，分别显示成功、已签到、失败和待处理。
- [ ] 网络超时有限重试；授权失效或需人工验证时停止重试并提示用户。手动重试仅处理未完成的社区签到。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
