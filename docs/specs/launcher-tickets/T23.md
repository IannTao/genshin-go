## What to build

扩展整体备份，计划冲突由用户选择，背包默认较新完整快照；验证全业务记录迁移及凭据排除。

批次 5；批准的拆分编号 T23。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 整体备份扩展到角色和武器计划及背包，继续排除登录授权。
- [ ] 恢复前预览并备份；计划冲突由用户选保留版本，背包默认较新完整快照且不累加。
- [ ] 验证完整迁移后的 UID、抽卡、成就、计划、背包及采集时间，并验证旧快照的明确选择。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
