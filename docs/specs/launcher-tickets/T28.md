## What to build

核实整体复用许可，提供可追溯源码和 Windows 构建产物，在干净环境完成安装与六批关键流程验收。

批次 6；批准的拆分编号 T28。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 提供可追溯源码与 Windows 构建产物，核实复用许可及应保留的声明。
- [ ] 在干净 Windows 环境验证安装或运行步骤及六批关键流程，保留可复核验收证据。
- [ ] 未验证服务、真实账号或注入能力明确记录为未完成，不能以无头测试或占位页面替代首期完成。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
