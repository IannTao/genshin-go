## What to build

复用计划管理与库存输入，覆盖武器等级和突破，保存计划并展示材料需求。

批次 5；批准的拆分编号 T21。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 复用计划管理，在界面创建并保存按 UID 归属的武器计划。
- [ ] 覆盖武器等级与突破，核实材料来源并计算需求，支持手填库存扣减。
- [ ] 重启恢复、数据隔离和历史删除规则有效；用可核算样例验证结果。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
