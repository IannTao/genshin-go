## What to build

整体备份与标准导出分开，迁移 UID 记录且不含凭据；恢复预览并合并，换机后重新扫码。

批次 4；批准的拆分编号 T18。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 提供区别于 UIGF/UIAF 导出的整体备份与恢复入口。
- [ ] 备份包含 UID、抽卡及成就记录，不包含登录凭据；换电脑仍需重新扫码。
- [ ] 恢复前预览、自动备份并遵守去重与成就合并规则；验证迁移后记录一致。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
