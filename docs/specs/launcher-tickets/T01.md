## What to build

自动发现和手选安装目录、保存默认目录、处理无安装和路径失效，并启动真实游戏；在这条流程中引入已确认的应用环境测试边界。

批次 1；批准的拆分编号 T01。每批完成真实流程验收后再推进下一批；原生阻塞关系仅表示技术前置。

沿用 Rust UI 和领域术语，遵循本机数据所有权与平台边界。首次使用的接口、资源与权限须核实；无法验证时报告具体阻塞，不自动缩减范围。

## Acceptance criteria

- [ ] 自动发现和手动选择有效国服安装，多目录可选默认，重启后保持选择。
- [ ] 无安装或路径失效有可操作提示；有效目录能普通启动真实游戏。
- [ ] 先在该功能中建立可替换应用环境边界，再以 NSH 根组件验证选择与启动行为。
- [ ] 通过已确认的 NSH 根组件交互边界验证本票可观察行为；纯逻辑按需补测试，平台或服务实际流程提供真实验证结果。
- [ ] 运行与变更对应的 Rust 格式、NSH 检查及交互测试，交付时记录实际通过项与未完成项。
