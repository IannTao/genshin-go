# GGScanner 启动同步按游戏 UID 和数据类别分别保存

每次通过启动器启动原神时，GGScanner 提供的成就、已拥有角色、武器和圣遗物可能在不同时间到达。启动器按本次实际登录的游戏 UID 归档，每收到一个完整类别就立即保存并更新该类的同步时间，其余类别保留上次结果。即使成就直到退出游戏都未到达，本次已经取得的角色和装备仍可查看。

玩家可随时手动标记或取消成就，修改立即生效。该 UID 的下一次完整成就扫描会覆盖此前的完成状态；只收到其他类别时，手动修改继续有效。完整武器列表和圣遗物列表各自替换对应库存，并各保留上一份可恢复记录，使游戏内已消耗的装备能及时从当前库存中移除。

成就分批到达时，启动器立即保存已收到的完成 ID，确认该 UID 的成就列表完整后才撤销缺席 ID 的完成标记。首版先同步完成状态，保留已有的 UIAF 完成日期并注明来源，缺少日期时显示「完成时间未知」。GGScanner 今后若提供逐项实际完成时间，以其为准。
