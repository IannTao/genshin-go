# Genshin Go · Windows 功能与交互清单

适用于 Windows 国服官服。玩家可以直接启动游戏，也可以在未授权米游社的情况下维护本机 UID 资料。本次梳理依据工作区源码、一期 T01–T28 票稿、单账号授权修订（#30）、GGScanner 专项规格（#41）、分类别背包快照与米游社材料同步（ADR 0002 修订、T19）及可选注入模块选型核查。GitHub 在线状态未能回读。「已有入口」表示当前工作区已接入相应功能；发布、实机验收及线上服务可用性需分别核实。

## 设计稿与评审入口

- 浏览器可点击评审稿用于评审最新桌面交互。顶栏「⋯」菜单可直接切换 27 个画板或重置演示。数据、操作结果和文件路径均为演示样例。[可点击评审稿](launcher-workbench-review.html)
- OpenPencil 可编辑稿保留此前的布局。26 个页面各有浅色／深色与展开／图标侧栏四种组合，共 104 张画板。从「启动器 · 首页」开始，图标可在「shadcn/ui · 引用组件」页编辑。[OpenPencil 可编辑稿](genshin-go-workbench-appearance.fig)
- 正式 UI 由 Rust 根组件挂载。当前原生导航有六个入口，祈愿、背包和整体备份仍从「角色资料」进入。下文的九模块导航和窗口行为以 HTML 原型为准，业务功能状态以当前源码为准。[Rust 根组件](../src/lib.rs) · [原生导航](../src/launcher.rs) · [角色资料](../src/profile.rs)

## 桌面窗口与导航

HTML 原型使用一条贯穿窗口的顶栏。左侧放侧栏开关与 Genshin Go 应用名称，右侧放主题切换、「⋯」原型工具和 Windows 风格的窗口控制。各页标题在内容区显示。国服范围在相关业务页面说明。

| 窗口操作 | 浏览器原型行为 |
| --- | --- |
| 最小化 | 隐藏窗口，在页面底部显示「Genshin Go」入口。点击还原后回到原页面，并恢复最小化前的窗口尺寸状态。 |
| 最大化／向下还原 | 最大化时铺满浏览器可视区域，再按一次恢复原尺寸。双击顶栏空白处也可切换，按钮图标和提示随状态更新。 |
| 关闭 | 隐藏窗口并显示「打开 Genshin Go」。重新打开后以普通尺寸显示首页。 |

窗口控件模拟启动器窗口行为，作用于浏览器中的原型。

侧栏主区按顺序排列「首页」「游戏管理」「米游社」「角色资料」「祈愿分析」「背包仓库」「成就管理」「扩展」。底部固定「系统设置」，通过分隔线与主区区分。展开时显示图标和名称，收起后仅显示图标，保留当前项高亮、悬停提示与底部设置入口。

| 页面 | HTML 原型交互 |
| --- | --- |
| 角色资料 | 在「已拥有角色」与「养成计划」之间切换，管理当前 UID。 |
| 祈愿分析 | 在「总览」「历史」「角色」「武器」之间切换。总览并排展示各卡池统计，记录视图支持按卡池和关键词筛选。导入预览返回祈愿模块。 |
| 背包仓库 | 在「武器」「圣遗物」「材料」之间切换，支持名称、类型、品质搜索及排序。选择历史快照可查看采集时间和物品详情。 |
| 成就管理 | 左侧分类显示完成数量，右侧支持名称、描述、ID、版本和完成状态筛选。分阶段成就可展开或收起，勾选后即时更新演示统计。 |
| 系统设置 | 「外观」提供主题与侧栏设置。「备份与恢复」提供整体备份和文件选择入口，取消或确认恢复后回到该页签。 |

## 关键状态与交互约定

| 流程 | 进入条件 | 可观察的结果与恢复路径 |
| --- | --- | --- |
| 普通启动与启动同步 | 默认目录有效，扫描器可选 | 游戏启动结果与 GGScanner 同步结果分行独立报告。扫描准备阶段可点击「直接启动游戏」跳过（15 秒超时自动继续启动）；启动后可点击「取消本次同步」并正常关闭本次专用扫描器实例。同步数据写入实际登录的游戏 UID，保留当前浏览 UID。 |
| 下载与维护 | 同一安装目录上存在任务 | 侧栏底部跨页固定显示传输任务状态与进度，点击直达任务；中断时原位提示原因而不强制跳页；重开后由玩家手动点击「继续下载」。安装、更新或修复持有该目录时，普通启动显示具体等待原因。 |
| 授权、签到与材料同步 | 保存唯一米游社账号 | 米游社页内完成扫码、过期刷新与取消；仅同一账号续期成功才替换凭据。签到失败仅重试未完成项，奖励待确认时只刷新奖励。当浏览 UID 与已授权账号绑定的 UID 一致时，背包仓库开放「从米游社同步材料」。 |
| 手动文件导入与整体恢复 | UIGF、UIAF、GOOD 或整体备份文件 | 选择文件 → 核对归属、采集时间与类别覆盖 → 预览差异 → 自动备份现状并确认 → 显示实际写入结果与备份路径。整体恢复支持跨多个 UID 预览，并要求对冲突的养成计划或手填库存逐项显式选择保留版本。仅预览或取消均不写入。 |
| 空间切换与清理 | 未授权也可操作 | 当前浏览 UID、米游社签到账号、实际游戏登录 UID 与单次导入目标 UID 相互独立。移除账号与删除历史记录使用不同确认框，均展示完整目标标识，Enter 默认聚焦「取消」，Esc 安全返回。 |
| 窄窗口与键盘 | Windows 桌面 | 首页窄窗口优先裁切右侧风景，保留左侧主操作与完整路径换行显示。数据工作台自适应可用宽度。Tab 按阅读顺序移动焦点，确认框打开时将焦点限制在框内并在关闭后归还。 |
| 主题与侧栏 | 启动器任意页面或系统设置 | 顶栏按钮或「系统设置 → 外观」可切换浅色与深色主题，并在 212 px 展开侧栏与 72 px 仅图标侧栏之间切换。收起侧栏后主工作区自动扩展利用回收的横向空间，侧栏保留当前项高亮、下载任务缩略指示及悬停提示，设置跨页面持久化。 |
