# T03 范围修订与验证记录

原任务要求启动器用已保存账号登录游戏。2026-11-17 实机验证期间，用户确认游戏从启动器普通启动，登录与切换在官方客户端内完成。保存的米游社授权用于后续自动签到和扫码获取祈愿记录。此决定取代原票据的账号启动和双账号切换验收条件。[原 GitHub issue #4](https://github.com/IannTao/genshin-go/issues/4)

首发范围中的“本机多账号启动流程”现指普通启动和本机多账号授权两项独立功能。本机数据所有权及 Windows 凭据保护约定继续适用。[本机数据与平台边界 ADR](../adr/0001-local-data-and-platform-boundary.md)

## 交付行为

- 普通启动使用已验证的游戏目录请求 Windows 打开客户端。客户端负责显示登录流程和管理当前游戏账号。
- 米游社扫码、保存、恢复和重新扫码沿用 T02，独立于普通启动。后续签到和祈愿记录功能分别验收。[T02 验证记录](t02.md)

## 验证范围

- T01 已在 Windows 验证原生普通启动请求。本轮未再次启动真实游戏，未重新验证客户端内登录。[T01 验证记录](t01.md)
