# T15 祈愿统计验收

在 Windows 的「角色资料」中导入 UIGF 档案，选中记录所属的 UID。「祈愿统计」按卡池显示本机已导入的抽数、3–5 星数量和星级未知数量。统计读取该 UID 的所有已保存记录，翻页和重复导入相同记录时结果一致。每个记录 ID 对应一抽，`count` 表示获得的物品数量。

五星保底进度以最近一次已知五星为起点。只有这次五星之后的同池记录一直到现在都完整，页面的累计抽数和最多还需抽数才适用。UIGF 记录 ID 可用于排序，无法证明记录连续。星级缺失或无效时归入「星级未知」。缺少五星、近期星级未知或末尾记录与保底上限冲突时，页面显示进度未知。UIGF 档案也缺少足以确定 UP 或定轨状态的上下文。

## 重跑验收

在仓库根目录用 PowerShell 7.2 或更新版本执行以下命令。验证通过真实 Rust 根组件完成，使用隔离数据目录和合成 UIGF 档案。

```powershell
./docs/validation/t14-windows.ps1
./docs/validation/t14-windows.ps1 -Native
```

脚本验证角色双池共享、同秒数字 ID 排序、各池稀有度、历史不足、超出保底上限的记录、重复导入、分页、UID 切换及删除历史。加 `-Native` 使用 Windows 原生宿主。

公开规则和物品星级已通过官方资料核对。Windows 交互验证使用合成档案，溯光编码由已发布的导出实现交叉核对。
