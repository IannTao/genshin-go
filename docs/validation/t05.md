# T05 验证记录

任务为 [#6 移除账号与独立删除历史记录](https://github.com/IannTao/genshin-go/issues/6)。

- 完整 Windows 检查通过。包括 Rust 格式、Clippy、任务同步脚本离线检查、两处 `nsh check`，以及根目录 `nsh test` 的 11 项通过、4 项默认跳过和隔离夹具的 22 项通过。
- SQLite 和 DPAPI 测试确认移除后无法读取原授权，两个 UID 的历史记录和当前选择得以保留。重新保存同一账号后，旧记录各保留一份，其他窗口持有的旧授权版本无法续期或移除新授权。历史删除测试覆盖关联账号仍保留、未知 UID 拒绝以及事务失败时回滚。
- 在独立 `LOCALAPPDATA` 中运行 Windows 原生 Rust 根组件。使用合成 DPAPI 授权和两组示例记录，实际验证移除授权、重开恢复、列出两个 UID、取消删除及按确认的 UID 删除。直接查询该独立 SQLite 数据库确认只删除所选 UID 的记录。
- 米游社 SDK 实时探针用同一设备 ID 创建并轮询两张二维码。通过两个根组件进程在同一数据目录验证二维码刷新和重开后复用设备 ID。
- Windows 原生实测使用独立本机数据目录。用户完成第一次扫码并验证游戏 UID，随后重开启动器并移除该授权。第二次用同一账号扫码成功，恢复相同的账号与 UID，原 UID 数据空间仍只有一份。用户确认第二次扫码时手机未提示「新设备」。再重开后启动器恢复了该授权，并用 DPAPI 解密后的 Cookie 重新查询到相同的游戏 UID。

运行 `./docs/validation/t05-windows-live.ps1` 可在新建的独立本机数据目录复验。
