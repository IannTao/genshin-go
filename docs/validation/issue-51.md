# #51 Windows 窗口控件验收

启动器沿用 NSH 的 Windows 原生标题栏。最小化保留当前窗口和页面，关闭会结束窗口进程。新进程按启动入口的默认尺寸打开，页面从首页开始。

## 重跑步骤

在 Windows 桌面打开一个专用的 PowerShell 会话，从仓库根目录启动应用。使用独立的数据目录，避免读取日常使用的授权和设置。复验结束后关闭该会话。

```powershell
$env:GENSHIN_GO_DATA_DIR = Join-Path ([IO.Path]::GetTempPath()) ('genshin-go-window-' + [guid]::NewGuid())
cargo run --locked
```

1. 在普通窗口打开「扩展」，记下窗口尺寸。点击「最小化」，再从 Windows 任务栏点击 Genshin-Go。核对「扩展」仍选中，窗口回到原尺寸。
2. 点击「最大化」，核对窗口扩大，按钮变为两个重叠方框，Windows 报告的按钮名称变为「还原」。再次最小化，再从任务栏点击 Genshin-Go，核对「扩展」仍选中，窗口仍处于最大化状态。
3. 点击「还原」，核对普通尺寸、单方框图标和「最大化」按钮名称。双击标题栏空白处两次，核对窗口先最大化再回到原尺寸。分别悬停按钮，核对当前 Windows 版本显示的提示。
4. 留在「扩展」并最大化，点击「关闭」。确认 PowerShell 返回提示符后，再次运行 `cargo run --locked`。核对启动器以普通尺寸打开，选中「首页」。

## 实机记录

2026-11-22，在 Windows 11 26H2（26300.9974）使用 Cargo 和锁定的 NSH 0.4.0 依赖构建并验证起始提交 `4dbde7b` 的原生启动器。普通窗口的捕获范围为 1042 × 751 px，最大化后为 4096 × 1680 px。

| 操作 | 实测结果 |
| --- | --- |
| 普通窗口在「扩展」最小化并重新激活 | 回到同一窗口和「扩展」页，捕获范围仍为 1042 × 751 px。 |
| 最大化窗口在「扩展」最小化并重新激活 | 回到同一窗口和「扩展」页，仍处于最大化状态。 |
| 按钮和双击标题栏空白处 | 两种方式都能在最大化和普通尺寸间切换。「扩展」保持选中，图标及 Windows 可访问按钮名称随状态更新。 |
| 关闭最大化窗口后以默认参数重开 | 原进程退出，新进程以 1042 × 751 px 的普通窗口打开并选中「首页」。 |

两次最小化后均通过桌面验证工具重新激活原窗口。任务栏图标点击路径待补验。已观察到最大化按钮悬停时显示 Windows 贴靠布局，单独的悬停文字待核对。
