# T19 背包快照来源与验证

## 来源

- Inventory Kamera 可通过 Windows 游戏窗口和 OCR 采集武器、圣遗物、材料、角色培养素材。它支持按类别、星级或等级筛选，也可导出中途停止的扫描。导入时须由用户确认文件提供的类别已经完整采集。上游 Windows 程序要求管理员权限，启动器只读取用户选取的本地 JSON。[上游使用说明](https://github.com/Andrewthe13th/Inventory_Kamera#running-inventory-kamera) · [Windows 清单](https://github.com/Andrewthe13th/Inventory_Kamera/blob/01e08c0527149ef40083608f50f16a2963293285/InventoryKamera/app.manifest)
- 核对了 Inventory Kamera 提交 `01e08c0` 的 GOOD v2 导出实现。武器与圣遗物是逐件数组，材料为 GOOD 标识到整数数量的映射。导出文件没有游戏 UID 或时区。文件名 `genshinData_GOOD_yyyy_MM_dd_HH_mm.json` 记录写文件时的本地时间，精确到分钟。若采集时间与导出时间不同，应填写原始采集时间。[导出实现](https://github.com/Andrewthe13th/Inventory_Kamera/blob/01e08c0527149ef40083608f50f16a2963293285/InventoryKamera/data/GOOD.cs)
- 启动器读取结构兼容的 GOOD v1、v2 和 v3 文件。完整背包包含武器、圣遗物和材料。可以只导入文件提供的类别，缺席类别沿用已有记录。Inventory Kamera 可能省略库存为零的类别，玩家也可以在核对游戏库存后明确确认缺失类别为空。GGScanner 导出的 `genshin_export_yyyy-MM-dd_HH-mm-ss.json` 同样可由原始文件名预填本地导出时间，导入前须确认并补全时区偏移。带 `metadata.capturedAt` 的文件保留该 RFC 3339 时间，备份通过此字段及 `metadata.uid` 保留时间和归属。[上游 GOOD 格式](https://github.com/frzyc/genshin-optimizer/blob/master/libs/gi/good/src/schemas/good-format.ts) · [本机读取实现](../../src/inventory/archive.rs)
- Leyline 在 GOOD v3 中提供材料数量，以及 `gi_player.uid` 和 Unix 毫秒采集时间 `timestamp`。启动器将该时间显示为 UTC，保留毫秒精度，并校验文件中声明的归属和时间。网页导出可能保留空集合并通过 `gi_off` 标记隐藏的数据，导入时拒绝这类不完整库存。GGScanner v2026.11.15 的 GOOD 导出提供装备类别，模型没有材料字段。[Leyline 文件规范](https://teyvat.me/developers#the-file) · [GGScanner 导出数据模型](https://github.com/Anyrainel/GGScanner/blob/4274dfffffe1dc19a5738c1c2450766c08d3024b/genshin/src/scanner/common/models.rs)

## 交互验证

在 Windows 上给 `GENSHIN_GO_DATA_DIR` 指定一个新的绝对路径后，运行
`nsh test App.test.tsx --filter inventory`。合成夹具覆盖选择 UID、补全时区、
GGScanner 原始文件名时间预填、预览与备份、多分类覆盖备份回显、浏览三类库存、
备份重读、数量替换、旧快照选择与旧分类快照缺类提示、重启持久化、按 UID 清除历史、
空库存确认、重复材料标识校验、Leyline 文件归属与时间、部分共享拒绝、只导入装备时保留
已有材料数量，以及只导入材料时保留已有装备。

已在 Windows 原生窗口下用隔离数据库导入真实 GGScanner GOOD v3 导出（`genshin_export_2026-11-22_16-25-43.json`，声明游戏 UID `249917230`）。启动器从文件名自动预填本地导出时间 `2026-11-22T16:25:43`，补全 `+08:00` 后完成预览、备份与导入；导入后及重开启动器均完整回读武器 253 件（第 1/9 页）与圣遗物 2528 件（第 1/85 页），来源为 `yas-GOODScanner · GOOD v3`，采集时间为 `2026-11-22T16:25:43+08:00`，缺席的材料类别显示为尚未采集，隔离目录验证后已清理。

真实材料核对阻塞：目前无法取得包含材料的真实 GOOD 文件，因此尚未完成材料真实库存与原始采集时间的真机导入对照，#20 继续保持打开待后续补验。
