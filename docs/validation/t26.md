# T26 固定插件版本核验

[GitHub Issue #27](https://github.com/IannTao/genshin-go/issues/27) 的本地发布票稿见 [T26](../specs/launcher-tickets/T26.md)。

精选目录记录的上游提交为 `1830f9d770ecb9c895ba98b9a933973eabe36e7a`。目录声明的本机格式是 Windows x64 插件目录，包含 `FufuLauncher.UnlockerIsland.dll` 和 `config.ini`，运行需要管理员权限。上游项目标注 AGPL-3.0。现有发布信息还不足以建立该提交与本机 DLL 的对应关系，随包分发所需的许可证告知和对应源码也待核实。[插件目录](../../assets/plugin-catalog.json) · [上游源码仓库](https://github.com/FufuLauncher/FufuLauncher.UnlockerIsland)

「扩展」打开插件详情时，使用安装时保存的 SHA-256 摘要复核受管文件。文件缺失或内容发生变化会显示原因，并提供「重新安装」。显示的目录版本来自安装记录，内容摘要只验证本地文件与该记录一致。Rust 回归测试覆盖 DLL 被替换后检测失败、拒绝常规更新和重新安装恢复。Windows 上以 `nsh test nsh.json` 使用临时应用数据目录安装测试文件，替换其中的 DLL 后重新打开根组件，确认「扩展」提示摘要不一致，点击「重新安装」后恢复为「已安装」。

真实游戏内模块加载、启动结果反馈和发布条件仍未验收。
