# T11 社区签到验证记录

任务见 [Issue #12](https://github.com/IannTao/genshin-go/issues/12)。

## 接口与授权

- 查当天签到状态使用 `GET /apihub/wapi/getUserMissionsState?point_sn=myb` 和已保存的网页 Cookie。只读取社区签到任务 `58` 或 `continuous_sign`。
- 原神版区签到使用 `POST /apihub/app/api/signIn`，请求体为 `{"gids":2}`，使用同一账号扫码返回的 App 会话 `stuid`、`stoken`、`mid`，以及原扫码设备标识。App Cookie 由 Windows DPAPI 单独加密，网页 Cookie 继续用于状态查询和原有功能。历史授权可以查询签到状态，提交时如缺少 App 会话则提示重新扫码。
- 匿名状态查询和使用失效合成凭据及 DS 签名的提交分别实测 HTTP 200、`retcode=-100`。同域名旧 `/apihub/sapi/signIn` 路由返回 HTTP 404。[固定版本 UIGF 协议](https://github.com/UIGF-org/mihoyo-api-sdk/blob/7c3107f95b72e7324af966b2e8989eb8375e5fc7/src/community.tsp) · [MiyoQian 社区签到客户端](https://github.com/Marchen-orz/MiyoQian/blob/main/miyouqian/tasks/bbs.py)
- 公开任务查询实测返回任务 `58`，名称为「打卡」，标识为 `continuous_sign`，阈值及上限均为 1。[米游社公开任务响应](https://bbs-api.miyoushe.com/apihub/wapi/getMissions?point_sn=myb)
- 旧扫码 App 会话能查询当天任务，提交签到返回 `-100`。扫码使用米游社社区 App 注册和 `bbs_cn` 后，同一账号完成续期，App 会话能成功提交签到。

## 日期与休眠

公开任务的启用时间 `946656000` 对应北京时间 2000-01-01 00:00。本地调度据此使用北京时间 00:00 切换签到日，提交前读取服务端当天状态。任务启用时间与每日刷新时间是不同的字段含义，实际刷新时刻待实测。Windows 使用包含和排除休眠的两个中断计时器检测恢复。[Microsoft Windows 计时函数文档](https://learn.microsoft.com/en-us/windows/win32/sysinfo/time-functions)

## 2026-11-19 Windows 实机

用 `nsh test nsh.json --target windows` 打开独立数据目录。用户用米游社扫码续期同一账号后，首次重新打开的窗口中，状态查询和提交均返回 HTTP 200、业务码 0，界面显示「社区签到：成功」。再次打开时只查询当天状态，显示「社区签到：已签到」。

跨日与休眠恢复通过 NSH 隔离交互使用可控时钟复现。本次实机未等待服务跨日，也未使 Windows 实际休眠。
