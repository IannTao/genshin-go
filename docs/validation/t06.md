### 重跑官方下载探针

在 Windows PowerShell 中使用一个新的隔离目录，依次执行 `pause`、`resume`、`finish`。前两次分别在写入至少 32 MiB 和 96 MiB 后暂停。最后一次下载剩余资源并完成安装，需约 150 GB 空间。三个命令通过单独的测试进程验证任务跨进程保存，配置和文件都保存在探针目录。

```powershell
$env:GENSHIN_GO_INSTALL_PROBE_ROOT = Join-Path (Get-Location) 'target/t06-live-recheck'
foreach ($step in @('pause', 'resume', 'finish')) {
    $env:GENSHIN_GO_INSTALL_PROBE_STEP = $step
    cargo test --locked --lib game_install::windows::tests::official_installation -- --ignored --nocapture
    if ($LASTEXITCODE -ne 0) { throw "T06 probe failed at $step" }
}
```

探针安装完成后，把启动器的 `LOCALAPPDATA` 指到隔离配置，再用**使用此目录**选择 `target/t06-live-recheck/games/Genshin Impact Game`，点击**普通启动**。记录 Windows 是否接受请求及客户端是否进入登录界面。
