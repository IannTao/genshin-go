# T14 祈愿记录验收

在 Windows 的「角色资料」中选择 UIGF JSON 文件，或输入路径后点击「读取 UIGF 文件」。多 UID 档案可以按记录组预览。文件声明的有效 UID 对应同名数据空间。遇到无法识别的 UID 时，先核对文件归属，再明确选择目标数据空间。

预览按 UID 和记录 ID 统计新增、重复与冲突。确认新增记录前，启动器将该 UID 原有的祈愿记录保存为独立的 UIGF 文件，路径显示在导入结果中。确认后，切换到对应 UID 即可分页查看记录。列表和新导出文件的时间统一使用 UTC。

「导出 UIGF v4.2」将当前 UID 的祈愿记录保存到本机数据目录下的 `wish-exports`。「导出到其他目录」可指定位置。导入前备份存放在本机数据目录下的 `wish-backups`。两类文件都可以在文件管理器中独立管理。

在仓库根目录运行以下命令，使用临时数据和合成档案验证 SQLite、备份、重复与冲突、重启、UID 隔离和导出往返。

```powershell
./docs/validation/t14-windows.ps1
./docs/validation/t14-windows.ps1 -Native
```

第二条命令通过 NSH 的 Windows 原生宿主运行同一套交互。脚本会打印隔离数据目录，供检查生成的备份和导出文件。
