## 奖励与日期

- 匿名读取米游社 `getMissions?point_sn=myb` 返回业务码 0。「打卡」是任务 `58`（`continuous_sign`），`points=30`，`is_auto_send_award=true`。启动器从此接口读取奖励数量。[米游社公开任务接口](https://bbs-api.miyoushe.com/apihub/wapi/getMissions?point_sn=myb)
- 用已有米游社授权读取 `getUserMissionsState?point_sn=myb` 返回业务码 0。当天「打卡」任务返回 `happened_times=1` 和 `is_get_award=true`。日历以 `is_get_award=true` 确认已领取。提交成功后再次读取任务状态，等待该字段确认奖励到账。[UIGF SDK 接口定义](https://github.com/UIGF-org/mihoyo-api-sdk/blob/7c3107f95b72e7324af966b2e8989eb8375e5fc7/src/community.tsp)
- 授权状态响应未提供任务日期。日历沿用 [T11](t11.md) 的北京时间日期，在请求返回时检查日期是否已切换。公开定义的 `active_time` 表示任务启用时间，服务端每日刷新时刻仍待跨日实测。日历保留当前会话近七个北京日期内检查到的结果。
